# aiti-prompts

> ❝ **我的输入是我宝贵的财富——好话不说二遍。** ❞

pi-web 的 **prompt 片段收藏库**：把说过的好话、好用的指令收藏起来，随时取用。

- **收藏库**：prompt CRUD + 树形分组（照 aiti-cmd 命令管理）
- **会话提取**：从历史会话的 user 消息里多选批量入库（你的表达习惯是最好的语料）
- **收藏输入**：聊天输入框的 📌 按钮，把当前输入一键存库
