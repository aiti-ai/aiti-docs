# Feedback & Issue Reports

Two ways:

1. **From the pi-web UI (recommended)**: the "Report an issue" toolbar button → fill the dialog (sanitized environment info attached automatically) → review the preview → go straight to GitHub.
2. **Manually**: [open an issue](https://github.com/aiti-ai/aiti-ai/issues/new). Please include: what happened, steps to reproduce, expected behavior, and your environment (browser/platform).

<FbPrefill />

## Before reporting

- Search [existing issues](https://github.com/aiti-ai/aiti-ai/issues?q=is%3Aissue) to avoid duplicates
- Check the [extension docs](/en/extensions/) and [changelogs](/en/changelogs/) — many questions are already answered
- Remove API keys / internal addresses / personal data before submitting (the pi-web dialog applies best-effort redaction — double-check the preview)
