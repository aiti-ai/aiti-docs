# demo

> ❝ **The framework needs examples before people have a model to follow.** ❞

The full-slot demo extension for the pi-web extension framework: covers `server.startup/shutdown/api/middleware`, all `ui.*` slots, and the client bundle protocol, used to validate the framework during development.

> It can be deleted from prod once its mission is done. Use it as a reference when writing extensions (see [aiti-agent extension points](/en/devtools/extension-points.md)).
