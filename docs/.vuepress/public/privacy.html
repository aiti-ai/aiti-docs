隐私说明 · Privacy Policy

aiti-devtools 浏览器扩展（Chrome / Edge / Firefox）—— 最近更新 / Last updated: 2026-11-09

一句话结论

本扩展不收集、不上传任何遥测或个人数据。所有配置仅保存在你的浏览器本地；运行时通信只发往你自己配置的服务地址。

TL;DR: This extension collects no telemetry and no personal data. All settings stay in your browser's local storage, and runtime traffic goes only to service addresses you configure.

数据存储 / Data storage

配置（AI 目标地址、站点白名单/排除规则、桥地址）通过 storage.sync 保存在你的浏览器账号下；运行态缓存在页面本地 localStorage / storage.session。没有任何数据发往 aiti 或第三方。

Settings (AI target address, site allowlist/denylist, bridge address) are stored via storage.sync under your own browser account; runtime caches live in page-local localStorage / storage.session. Nothing is sent to aiti or any third party.

网络通信 / Network traffic

扩展只与你自己配置的服务地址通信——默认为本机 127.0.0.1 上的本地桥 / pi-web 工作台（也可改为你自己局域网/服务器上的地址）。通信内容为被调试页面的调试信息（快照、控制台输出、点选元素），且由你显式操作触发。扩展默认不注入任何页面——注入仅在你按需启用或加入白名单后发生。

The extension talks only to services you configure — by default a local bridge / pi-web workbench on 127.0.0.1 (changeable to your own LAN/server addresses). Traffic is debugging information about the page under inspection (snapshots, console output, picked elements), triggered by your explicit actions. Injection is off by default and only happens per your explicit enable or allowlist.

关于被调试页面 / About debugged pages

被调试页面的内容（DOM/控制台/网络）仅在调试会话期间发送给你选择的 AI agent（pi / Claude Code / opencode 等——它们是你自己的账号与服务）。aiti 不经手、不存储这些内容。

Debugged-page content (DOM / console / network) is only sent to the AI agent you chose for the debugging session (pi / Claude Code / opencode — your own accounts and services). aiti never sees or stores it.

权限用途 / Permissions

storage=本地保存设置；activeTab+scripting=按需向当前被调试页注入调试助手；host_permissions=任意网页可作为调试目标（默认关，用户显式启用）。

storage=local settings; activeTab+scripting=on-demand injection into the page being debugged; host_permissions=any webpage can be a debugging target (off by default, user-enabled).
