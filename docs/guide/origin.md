# 项目起源

## 一开始

最早用了一些其它的 AI agent 写代码。各有各的顺手和不顺手，但总觉得差一点：想要的工具链、想要的界面、想要的工作方式，都隔着一层。

## 改用 pi-web

后来换到 [pi](https://pi.dev) 和 [pi-web](https://github.com/agegr/pi-web)。pi 的引擎设计（扩展、技能、提示词模板、主题）很对胃口，pi-web 把会话管理、服务隧道这些做了个不错的底子。

于是就把日常开发搬了过来。

## 越加越多，回不去了

用着用着，开始往 pi-web 上添东西：会话面板、tag 管理、服务端口发现、页面内调试注入、MCP 桥……每加一个，就离上游远一点。

直到某一天发现：改动已经面目全非，代码合不回去，PR 也提不上了。与其守着"fork"的身份，不如按自己的方式发版，做自己的产品。

**aiti 就这么开始了**——基于 pi-web 的开源代码，加上我们自己积累的扩展，以独立品牌和独立发行版的形式维护。

## 先服务自己

这个发行版首先是**做给自己用的**：自己喜欢、自己顺手的 AI 开发工具。因为自己天天用，所以坏得快、修得也快；因为需求真实，所以不做花架子。

如果你也觉得顺手，欢迎一起用。

## 欢迎贡献

- **提交代码**：修 bug、补文档、提改进，都欢迎。
- **创建扩展**：aiti 的扩展框架是开放的，业务功能全部以扩展形式实现，可以基于它做自己的东西。见 [aiti-agent 扩展点](/devtools/extension-points.md)。
- **需要新的扩展点**：现有插槽不够用时，开 PR 到 **aiti-agent** 加扩展点（改 `lib/ext/types.ts` 的插槽与契约 + `components/ExtSlots.tsx` 的挂载位置），扩展本身仍然在你的仓库里写。
