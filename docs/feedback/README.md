# 反馈与问题报告

两种方式：

1. **从 pi-web 界面发起（推荐）**：工具栏「报告问题」按钮 → 弹窗里填写描述（自动附带脱敏后的环境信息）→ 预览确认 → 直达 GitHub 提交。
2. **手动**：直接 [新建 issue](https://github.com/aiti-ai/aiti-ai/issues/new)。报告请包含：现象描述、复现步骤、期望行为、环境信息（浏览器/平台）。

<FbPrefill />

## 报告前建议

- 搜索 [已有 issue](https://github.com/aiti-ai/aiti-ai/issues?q=is%3Aissue) 避免重复
- 看 [扩展文档](/extensions/) 与 [更新日志](/changelogs/)，很多问题已有答案
- 涉及 API key / 内部地址 / 个人数据的内容请自行删除后再提交（pi-web 弹窗已做 best-effort 脱敏，预览请再确认）
