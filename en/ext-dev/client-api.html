Client ctx API

The context received by the client bundle's default export function register(ctx). Source of truth: components/ExtSlots.tsx (ExtClientContext).

0. Ground rules

  • No react imports: h and all hooks come from the host (single React instance, host-shim delegation).
  • Component = (props) => ReactNode; props include currentSession ({ id, cwd, name?, firstMessage? } | null) and slot extras.
  • Rules of Hooks: hooks must run before any conditional return (this applies to host-injected hooks too).
  • Members marked ? may be absent on older hosts — check before consuming.
