Quick Start (aiti-agent workbench)

Get aiti-agent (the self-hosted web workbench, npm package @aiti-ai/pi-web) installed and chatting in 5 minutes.

Looking for the page-debugging toolchain (aiti-devtools: inject → bridge → connect AI)? That's the other main line: the devtools quick start. Full install details (three methods / system requirements / common commands / script transparency) live on Installation.

1. Install (pick one)

npm
# Node.js ≥ 22.19
npm install -g @aiti-ai/pi-web@latest
npx
# nothing installed to disk, every run pulls the latest
npx @aiti-ai/pi-web@latest
macOS / Linux
# no npm needed: prebuilt GitHub Releases artifact + sha256 verification, installs into your home directory
curl -fsSL https://aiti.pw/install.sh | sh
Windows
# PowerShell 5.1+ (built into Windows 10/11)
irm https://aiti.pw/install.ps1 | iex
Docker
docker run -d --name aiti --init -p 30142:30142 \
  -v aiti_data:/opt/aiti/data -v aiti_agent:/opt/aiti/agent \
  -v ~/workspace:/workspace \
  aitiai/pi-web:core        # GUI / voice / tunnels all-in-one → :full

Slow pulls in China? swap the image for registry.cn-hangzhou.aliyuncs.com/aiti-ai/pi-web:core (Aliyun ACR, same tags as Docker Hub).

2. Launch

pi-web

The CLI opens the browser automatically once the service is ready (default http://127.0.0.1:30141; Docker uses 30142). Open it manually if it doesn't.

3. First-run configuration

  • Models: sign in or fill an API key in the Models panel; or use the 🧙 wizard's "import from other agents" (auto-scans existing codex / zcode / opencode configs)
  • Session engine: bundled out of the box — the default local engine runs in-process via the SDK. Optionally install the global pi coding agent CLI (for the TUI, attach/spawn backends, or sharing config with terminal use: npm install -g @earendil-works/pi-coding-agent)

4. Out of the box (60+ built-in extensions)

No per-extension installs needed — the common entries are one glance away:

EntryWhat it does
🧩 ExtensionsExtension manager: enable/disable / online install / feature switches
📋 SessionsAll multi-agent sessions managed in one place (All Sessions)
⚡ CommandsReal PTY terminal + favorite commands
🧙 ModelsModel wizard / availability check / balance panel
🔀 TunnelsExpose ports to the outside world (TOTP)
📡 Model checkAvailability probing / rate-limit reminders

The full list and docs live in the extension registry.

5. Connect more agents (optional)

Agents whose CLIs are installed (Claude Code / Codex / Cursor / ZCode / Qoder / any ACP…) appear automatically in the new-session backend list; controlled logins start from the Agent Management panel. IM (DingTalk / Feishu / WeCom) connects via aiti-channels so group messages can delegate work too.
