What is aiti?

aiti (pronounced /aiti/, echoing a sneeze — "AI development as natural as a sneeze") is an AI development tool ecosystem powered by pi:

  • Main product · web workbench: aiti-agent is a self-hosted personal AI development workbench (npm package @aiti-ai/pi-web, built on the open-source pi-web project, see project origin) — browser-first with 60+ built-in extensions out of the box: multi-agent session management, model management, IM integration, terminal / virtual display / remote desktop, service tunnels, development lineage, config safety net … Because it shares pi's lineage, pi CLI and pi IDE extensions operate the same sessions; one command to install, one-command Docker start.
  • Page-debugging toolchain: aiti-devtools injects into Vite / Vue / Next / Svelte and other mainstream dev tools, and aiti-bridge retrofits any AI agent as an MCP bridge — bringing the AI to the page development front line, where the page itself becomes debuggable, interactive, and answerable. See /devtools/.

Install methods (npm / scripts / Docker)

Pick one — details in the install guide (system requirements / common commands / script transparency).

npm
# Node.js ≥ 22.19
npm install -g @aiti-ai/pi-web@latest
pi-web          # starts the service and opens the browser (default http://127.0.0.1:30141)
macOS / Linux
# no npm needed: prebuilt GitHub Releases artifact + sha256 verification, installs into your home directory
curl -fsSL https://aiti.pw/install.sh | sh
Windows
# PowerShell 5.1+ (built into Windows 10/11)
irm https://aiti.pw/install.ps1 | iex
