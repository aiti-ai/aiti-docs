什么是 aiti？

aiti（发音 /aiti/，谐音「阿嚏」——「AI 开发像打喷嚏一样简单自然」）是一个以 pi 为引擎的 AI 开发工具生态：

  • 主产品 · Web 工作台：aiti-agent 是自托管的个人 AI 开发工作台（npm 包 @aiti-ai/pi-web，基于开源项目 pi-web 构建，来历见项目起源）—— 浏览器为主操作面，60+ 内置扩展开箱即用：多 agent 会话管理、模型管理、IM 接入、终端/虚拟屏/远程桌面、服务隧道、开发血缘、配置安全网…… 与 pi 同源兼容，pi CLI 与 pi IDE 扩展可操作同一批会话；一条命令安装，Docker 一键启动。
  • 页面调试工具链：aiti-devtools 注入到 Vite / Vue / Next / Svelte 等主流开发工具，aiti-bridge 作为 MCP 桥改造任意 AI agent—— 把 AI 请到页面开发现场，页面就是可调试、可交互、可回答 AI 问题的对象。详见 /devtools/。

安装方式（npm / 脚本 / Docker）

三种方式任选，详见 安装指南（系统要求 / 常用命令 / 脚本透明性）。

npm
# Node.js ≥ 22.19
npm install -g @aiti-ai/pi-web@latest
pi-web          # 启动服务并打开浏览器（默认 http://127.0.0.1:30141）
macOS / Linux
# 无需 npm：GitHub Releases 预构建产物 + sha256 校验，装到用户目录
curl -fsSL https://aiti.pw/install.sh | sh
Windows
# PowerShell 5.1+（Windows 10/11 自带）
irm https://aiti.pw/install.ps1 | iex
